## 两次深度调研的关键结论（36 次检索）

### 失败模式 → 机制映射

| 失败模式 | 证据 | 对应机制 |
|---|---|---|
| 遗忘目标 | 计划是易失上下文，一步衰减 ~12 倍 | 主线文件唯一事实源 |
| 绕圈 | Claude Code 无循环检测（官方 issue 确认） | 已试路径 + 停滞熔断 |
| 停滞空转 | 过夜多代理 12-bug 事后剖析 | 增量门槛 + 单轮超时 |
| 上下文膨胀 | 一个 prompt 吃掉 53% 会话 | 每轮新会话 + 按需压缩 |
| 假完成 | "验证查了配置没查行为" | 验证行为而非存在 |
| 停止指令失效 | 禁令不跨会话继承 | 禁区编码进数据层 |
| 注入污染 | 6 小时 47 篇垃圾草稿 | 主线注入标记扫描 |
| 过夜烧钱 | 26 小时 $6,000 | 轮次/deadline/超时硬护栏 |
