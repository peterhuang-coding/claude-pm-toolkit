# Autopilot — 白班决策 / 夜班执行

## 1. 使命

用户每天只有 1~2 小时。系统把这段时间全部用于**关键决策**，其余时间代理围绕一条持久**主线**自主推进。

铁律：**聊天不是状态，主线文件才是。** 任何人/代理会话冷启动，第一件事是读主线；恢复永远靠主线 + 轮次摘要，不靠旧聊天。

## 2. 主线文件（唯一事实源）

位置：项目根 `.claude/autopilot/mainline.md`（纳入 git，决策可版本化）。目标 ≤1200 中文字符；超了说明任务拆得太粗。

结构（模板见 §8）：

- **目标**：一句话 + 2~3 条可验证验收标准。
- **已决策**：编号决策日志（D1、D2…），只追加不删除：决定 + 理由 + 日期。
- **当前任务**：唯一 work item：做什么 / 验收标准 / 预计轮次。
- **已试路径**：试过什么、结果、原因——防止代理绕圈。
- **待决策**：需要用户拍板的问题，每项 ≤150 字（格式见 §4）。最多 5 项。
- **禁区**：范围外、禁止触碰的东西。
- **进度**：已完成里程碑（带验证结果）、最近一轮摘要引用。

## 3. 白班四段式（/autopilot）

1. **简报**（≤5 分钟读完）：夜班增量、主线状态、待决策队列、关键 diff 抽查建议（≤2 处，让用户 30 秒判断方向对不对）。
2. **拍板**：逐项决策，立即写入已决策日志并移出待决策。
3. **派活**：确定今夜唯一的当前任务（含验收标准），写入主线。
4. **交接**：git checkpoint、验证主线非空、启动夜班。

## 4. 待决策项格式（每项 ≤150 字）

```
背景：2 行内说清卡在哪。
选项：A … / B … / C …
推荐：X。理由 1 行。
影响：不决策会怎样。
风险等级：低 / 中 / 高
auto-default：是/否（只有"低"风险项允许"是"——用户不回复则到点执行推荐项）
```

代理永远不自行拍板"待决策"项；只能追加、不能删除、不能假装已决策。"高"风险项永不 auto-default，必须等用户。

## 5. 夜班循环（autopilot.sh，无人值守）

每轮：**新会话** → 冷启动只读：主线全文 + 最近 2 份轮次摘要 + git status → 只做当前任务的最小实现 → 真实验证 → commit → 更新主线（进度/已试路径）→ 输出轮次摘要。

结束条件（任一）：
- 当前任务验收标准达成（DONE）
- **连续 3 轮无增量**（停滞检测：轮次前后 git 无任何变化）→ 脚本自动在待决策写入停滞项并停止，绝不静默重试
- 代理需要用户决策 → 写入待决策 + BLOCKED
- 轮次/时间预算耗尽

## 6. 防遗忘 / 防绕圈 / 防假完成

- **计划必须外置**：聊天里的计划是易失上下文，会快速衰减。任何计划、决策、下一步只信主线文件。
- **按"下一步需要什么"压缩**：写轮次摘要时只写恢复主线需要的最小信息（状态、commit、验证、下一步），不写流水账。
- 每轮开始对照主线检查：是否在重复"已试路径"里的做法 → 是则改路径或写决策项，禁止原样重试。
- 每轮必须产出可验证增量（commit 或工作区变化）；无增量 = 停滞轮。
- 验证必须跑真实命令、记录真实输出；禁止"应该没问题""预计可以"。
- **验证行为而非存在**：文件存在 ≠ 功能可用。验收标准要跑通真实行为（测试、脚本、命令），防"看起来完成、实际是死的"。
- **主观目标不可自动化**："更好看 / 更优雅"不是验收标准。必须翻译成机器可验证的信号，翻译不了就写成待决策项，禁止让代理对主观形容词自由发挥（会过早宣布完成或永远震荡）。
- 每轮新会话即自动 compact；旧聊天永远不恢复。
- 主线"当前任务"同一时刻只有一个；完成才换下一个。

## 6.5 决策回访

白班或夜班每完成一个里程碑，抽查"已决策"日志里与当前状态冲突的旧决策：标注"已过时"（追加说明，不删原文）。防止早期决策悄悄失效而无人察觉。

## 7. 与 PM 体系的分工

| 层 | 职责 | 保留 |
|---|---|---|
| /goal | 产品方向闸门 | 新产品/对标仍需批准；夜班不得越过 |
| Feature 台账 | 跨天事实源 | 不变 |
| handoff / TASK_ID | 会话交接协议 | 不变；夜班轮次摘要写同一 TASK_ID |
| **autopilot 主线** | **决策与进度的唯一主线** | 新增，git 跟踪 |
| /today /wrap-up | 巡检与复盘 | 不变 |

夜班只做主线批准范围内的最小推进；范围扩大的想法写进待决策，不自行扩展。

## 8. mainline.md 模板

```markdown
# 主线

## 目标
<一句话目标>
验收标准：
- [ ] <可验证标准 1>
- [ ] <可验证标准 2>

## 已决策
（只追加：D1 2026-08-25 决定 X，理由 Y）

## 当前任务
<唯一 work item：做什么>
验收标准：<怎么算完成>

## 已试路径
（试过什么 → 结果 → 原因）

## 待决策
（见 §4 格式，最多 5 项）

## 禁区
- <范围外 / 不碰的东西>

## 进度
- [x] <里程碑 + 验证结果>
- [ ] <下一个里程碑>
最近一轮：<round-N 摘要一句话>
```

## 9. 命令与脚本

- 命令：`/autopilot`（白班四段式）、`/autopilot status`（只读状态）、`/autopilot decide`（只处理待决策）、`/autopilot stop`（停夜班并写交接）。
- 脚本：`~/.claude/skills/autopilot/scripts/autopilot.sh`，参数 `--rounds N --until HH:MM --sleep-seconds N --max-stall N --round-timeout S`。默认 10 轮、停滞 3 轮停、60 秒间隔、单轮 1800 秒超时；`--until` 缺省为启动后 8 小时。
- 信任边界：每轮后检查主线是否出现提示注入标记（"ignore previous instructions" 等），命中即停机。
- 轮次产物：`.claude/autopilot/rounds/round-NNN.md`（marker、commit、增量判定、日志引用）。
